Loops are used to repeat a block of code multiple times without rewriting it.

Without loops, repetitive tasks would require many lines of code. With loops, the same task can be done in a few lines.

Why Loops Are Needed:
- Printing numbers in sequence
- Iterating over lists
- Repeating validations
- Automating repetitive tasks

Types of Loops in JavaScript:

for:
- Used when the number of iterations is known

while:
- Used when execution depends on a condition

do...while:
- Executes at least once before checking condition

switch:
- Used for multiple fixed conditions (menu-style logic)

Control Statements:
break:
- Stops the loop or switch immediately

continue:
- Skips current iteration and moves to next

Loops are essential for writing efficient and scalable programs.
