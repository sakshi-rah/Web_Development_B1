A function is a reusable block of code designed to perform a specific task.

Functions help to:
- Reuse code
- Organize logic
- Avoid repetition
- Improve readability and maintainability

Without functions, code becomes long and difficult to manage.

Why Functions Are Needed:
- Calculating totals
- Validating user input
- Displaying messages
- Performing repeated operations

Types of Functions in JavaScript:

Function Declaration:
- Named function
- Hoisted (can be used before definition)

Function Expression:
- Function stored inside a variable
- Not hoisted

Arrow Function:
- Modern ES6 syntax (ES6= ECMAScript 2015)
- Shorter and cleaner
- Commonly used in callbacks

Parameters & Return:
- Parameters are inputs passed into a function
- return sends a value back to the caller

Functions without return perform actions.
Functions with return produce results that can be stored and reused.
