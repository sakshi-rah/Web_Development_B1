An object is a collection of key–value pairs used to represent structured, real-world data.

Arrays store lists of values.
Objects store structured information about a single entity.

Example:
- Student
- Product
- User profile

Why Objects Are Needed:
- Group related data together
- Represent complex entities
- Pass structured data easily

Without objects:
Multiple separate variables for each property.

With objects:
All related data grouped logically inside one structure.

Object Terminology:
- Property: A key–value pair
- Key: Property name
- Value: Property data
- Method: Function inside an object

JavaScript uses Object Literal Notation, written using {}.

Objects are fundamental for working with APIs, forms, backend data, and real applications.
