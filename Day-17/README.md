CSS effects make the user interface interactive, user-friendly, and professional.

Used for:
- Buttons
- Cards
- Hover states
- Loading and feedback

Effects should enhance user experience, not distract users.

Topics Covered Today:
- :hover: Mouse interaction
- :focus:
- :active:
- transition: Smooth changes -> transition-property:transform, transition-duration:1s,    transition-timing-function:ease, transition-delay: 4s (shorthand: transition: transform 2s ease-out 0s); 
- transform: rotate(), translate(), scale(), skew(); 
- cursor: Mouse pointer style
- opacity: Transparency
- box-shadow: Depth effect
