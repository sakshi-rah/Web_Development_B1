## JavaScript Data Types:

Primitive Types:
- string
- number
- boolean
- undefined
- null
- bigint
- Symbol

Non-Primitive Type:
- object (includes arrays, functions, objects)

JavaScript is dynamically typed, meaning variable types can change at runtime.

The `typeof` operator is used to check the data type of a variable. It is commonly used for debugging and validations.

## Operators in JS:
Operators allow us to perform calculations and comparisons. Conditions allow the program to take decisions based on logic.
Decision-making is one of the most important parts of programming.

### Types of Operators in JS:

1. Arithmetic Operators: Used for calculations.
- `+` (Addition)
- `-` (Subtraction)
- `*` (Multiplication)
- `/` (Division)
- `%` (Modulus)
- `++` (Increment)
- `--` (Decrement)

2. Comparison Operators: Used to compare values.
- `==` (Loose equality)
- `===` (Strict equality)
- `!=` (Not equal)
- `!==` (Strict not equal)
- `>, <, >=, <=`

3. Logical Operators: Used to combine conditions.
- `&&` (AND)
- `||` (OR)
- `!` (NOT)

4. Conditional Statements:
if → Executes code if condition is true
else → Executes if condition is false
else if → Checks multiple conditions

5. Ternary Operator:
Short syntax for simple if-else conditions.

Real-Life Example:
If traffic signal is red → Stop
If green → Go
If yellow → Slow down

Conditions help programs make intelligent decisions.
