Tailwind CSS is a utility-first CSS framework.
It provides ready-made utility classes to style UI directly in HTML.
Instead of writing custom CSS, we compose styles using classes.

Tailwind does NOT give ready components.
It gives low-level building blocks.

Simple Definition for Students:
Tailwind CSS lets you style UI using small reusable classes instead of writing CSS files.

Traditional CSS vs Tailwind (Mindset Change):

Traditional CSS:
.card {
  padding: 16px;
  background-color: white;
  border-radius: 8px;
}

Tailwind CSS:
`<div class="p-4 bg-white rounded-lg"></div>`


What is Utility-First Approach?
Utility means a single-purpose class.
Each class does only one job.

Examples:
p-4 → padding
bg-blue-500 → background color
text-center → text alignment

UI is built by combining utilities.

Why Utility-First is Powerful?
- No context switching between HTML and CSS
- No class name thinking
- No unused CSS
- Faster development

Once the mindset is clear, Tailwind becomes very efficient.
