An array is a data structure used to store multiple values inside a single variable.
Values are stored in an ordered sequence, and each value has an index (position).
Important: Array index always starts from 0.

Why Arrays Are Needed:
- Store lists of data (students, products, marks)
- Avoid creating multiple variables
- Handle dynamic data efficiently
- Loop through collections easily

Key Concepts:

Index:
- Position of element in array
- Starts from 0 in array.
- index = array length-1

Length:
- Total number of elements in array
- Accessible using .length property

Methods:
- Built-in functions to modify arrays (push, pop, slice etc.)

Arrays are fundamental for managing structured data in JavaScript.
