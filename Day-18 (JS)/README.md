JavaScript (JS) is a programming language used to make web pages interactive and dynamic.

Without JavaScript, websites are static.
With JavaScript, websites behave like applications.

What HTML and CSS Can Do:
- HTML creates structure (buttons, inputs, headings)
- CSS styles the structure (colors, layout, spacing)

What They Cannot Do:
- Handle button clicks
- Validate forms
- Fetch data from APIs
- Update content dynamically

Why We Need JavaScript:
- Handle logic
- Handle events
- Handle data
- Modify content without page reload

JavaScript is the brain of frontend development.

Real-Life Example:
HTML → Button exists
CSS → Button looks good
JavaScript → Button performs action on click

JavaScript vs HTML vs CSS:
- HTML → Structure
- CSS → Styling
- JavaScript → Logic & Behavior

Analogy:
HTML → Skeleton
CSS → Skin & clothes
JavaScript → Brain & muscles

Where JavaScript Runs:
1. Browser (Frontend JavaScript)
- Runs inside Chrome, Firefox, Edge
- Used for UI interaction, DOM manipulation, API calls

2. Server (Backend JavaScript using Node.js)
- Used for APIs, databases, authentication

How Browser Executes JavaScript:
- Loads HTML
- Loads CSS
- Loads JavaScript
- Executes JS line by line
- JS can read and modify HTML & CSS after load

What JavaScript CAN Do:
- Handle events
- Validate forms
- Show/hide elements
- Change content and styles
- Fetch API data
- Use localStorage
- Create dynamic UI

What JavaScript CANNOT Do:
- Access user file system directly
- Read private files
- Access OS features without permission
- Directly connect to databases from browser

Browser JavaScript runs in a secure sandbox environment.

Why JavaScript is Mandatory:
- React, Angular, Vue are JavaScript-based
- Interviews focus heavily on JS fundamentals
- Strong JS = Strong frontend developer
