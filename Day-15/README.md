CSS Grid is a two-dimensional layout system.

It works with rows AND columns, unlike Flexbox which works in one direction.

Used for:
- Page layouts
- Dashboards
- Complex UI structures

Rule of thumb:
Flexbox → 1D layout (row OR column)
Grid → 2D layout (row AND column)

Grid Concepts:
- Grid Container: Parent element with display: grid
- Grid Items: Direct children of grid container
- Grid divides space into columns and rows

12-Column Layout:
Industry-standard layout system where page width is divided into 12 equal columns.

Common in:
- Bootstrap
- Admin dashboards
- Responsive layouts

Example:
- Header → 12 columns
- Sidebar → 3 columns
- Main content → 9 columns
- Footer → 12 columns
